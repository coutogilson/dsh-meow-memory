# PR body

## Summary

Adds the first Portuguese **model-facing** language pack: `src/prompts/pt-br/` with all nine
slots (`system-guide`, `reflect`, `dream-header`, `dream-atomic`, `dream-topic`,
`dream-project-summary`, `welcome-guide`, `labels`, `tools`), so `promptLang: 'pt-br'` works
out of the box instead of silently falling back to the Chinese pack.

Follow-up to the UI copy layer PR. The two are independent: that one translates what the user
sees, this one translates what the model reads. Either can merge first.

## Why this exists / the gap it closes

The UI copy layer already ships `pt-br` as a *UI* locale (the language registered through
`addLanguage`). `promptLang`, however, selects a directory under `src/prompts/`, and the
lookup is **literal**: `readSlotFile` joins the value straight into
`~/.dsh-meow/prompts/<lang>/<slot>.md` and `lib/prompts/<lang>/<slot>.md`, so `pt-br` matched
neither and a Portuguese-speaking user who set it got Chinese prompts with no warning. This
pack makes the value real, and the docs now spell the matching rule out.

## Notes for the reviewer

1. **`pt-br`, not `pt`** — this is Brazilian Portuguese, and I'm Brazilian, so that is what I
   can vouch for. A `pt` pack signed by me would quietly claim coverage of European Portuguese
   that I can't back. It also keeps the directory name identical to the UI locale id, so a user
   who picks *Português (Brasil)* in Settings → General → Language and mirrors it in
   `promptLang` gets one consistent language.
2. **`project.global` is `global`, following the `en` pack, not `全局`** — that value is the
   word the model writes into a memory's `project` field for globally applicable information
   and the code matches on it, so it behaves as an identifier rather than as prose. If you'd
   rather have a Portuguese word there, say the word and I'll adjust both this pack and
   `labels.md`'s contributor note.
3. **Docs now state the resolution rule** — `src/prompts/README.md` lists `en/` and `pt-br/` in
   the layout and adds one paragraph: the value is matched verbatim, a name with no matching
   directory (instance override or built-in) silently lands on `zh`. This is the trap I hit on
   my own instance (`promptLang: pt-br` with the override folder named `pt`), so it felt worth
   writing down rather than leaving it implicit.
4. **Instance overrides still win** — the existing resolution order is untouched:
   `~/.dsh-meow/prompts/<lang>/` → built-in `<lang>` → built-in `zh`. Anyone with a personal
   pack keeps full control and can override single slots.
